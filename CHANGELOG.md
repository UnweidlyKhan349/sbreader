# Changelog

Site and UI changes, newest last. Data changes are in [docs/data-history.md](docs/data-history.md).

- **Text-to-speech replaced** with the on-screen reveal engine, which is robust in background tabs and supports live speed changes mid-question.
- Subject chips showing no text: fixed centrally in `SBData.load()`.
- Mobile nav overflow and oversized hero heading fixed.
- "Also accept" moved onto the answer line via the shared `answerLineHTML()`, then restyled to match the "Answer:" text.
- Subject chip order set to Math → Physics → Biology → Chemistry → Earth & Space → Energy; Tossup before Bonus everywhere, including the settings panels.
- Stratified subject queue made fully round-robin, which fixed a report of 60% Physics in a 40-question session.
- In-session settings for solo; room settings editable by every player in multiplayer.
- All-subjects-off resets to all-on when the settings panel closes (solo and multiplayer).
- Room codes uppercased before joining.
- `N` shortcut added to home, moved to solo start, then reverted (it now only means next/skip during a session).
- π/Π, ∛, and "square/cube root of" equivalences added to grading.
- "Toss-Up" renamed "Tossup" everywhere; Tjsbt 2025 renamed TJSBT 2025.
- Multiplayer guests see the same lobby prompt as the host ("Ready when you are — click Start or press N to begin."); anyone in the room can start.
- Solo scrolls back to the question when moving to the next one.
- The page scroller reserves the scrollbar's width (`scrollbar-gutter: stable`), so the nav's "Bookmarked questions" link no longer shifts sideways when a page starts or stops scrolling.
- Catalog search highlights the matching text.
- Grading accepts equal decimals and fractions (`0.5` for `1/2`) and `ER` for endoplasmic reticulum.
- Grading: typos and "the key plus extra words" are no longer scored as correct. They're marked wrong with a "Close" hint, and the player presses Q (Override) if they meant it. Swaps that change the term (hypertonic/hypotonic, alkane/alkene, nitrate/nitrite, ...) aren't even close. Answers that drop part of the key ("carbon" for CARBON DIOXIDE) are wrong. Alternates written inside a key ("ITCZ OR INTERTROPICAL CONVERGENCE ZONE", "GREEN ACCEPT: EMERALD") and singular/plural forms now pass. Typing the key exactly ("+6") is no longer caught by a reject entry that only differs in punctuation ("6").
- Multiplayer: the host validates every message from a client (type, string lengths, known filter values, rate clamped to 0.5–2.5) and ignores peers that haven't joined. A player can't override a wrong answer to correct after someone else has scored the question.
- Multiplayer: removed Open Relay's shared TURN login, which no longer works. Connections use STUN only.
- The home page loads only `meta.json` (58 KB) instead of the whole question bank.
- Question cards in the catalog, bookmarks and both session logs use one shared renderer, so they all show "also accept" and "do not accept" lines.
- Added tests (`npm test`) and a CI workflow.
- Rebranded the site as **SB Reader** (page titles, nav brand, README).
- Grading: ranking answers must be in the keyed order. Typing the item numbers with commas or spaces in the wrong order (`3, 2, 1` for `1, 3, 2`) used to pass, and longer ranking stems ("Order the convectively available potential energy of the following…", "Place the following in chronological order") were graded as order-free sets.
- Catalog results are listed in packet order (tournament, round, question number, tossup before bonus) instead of storage order.
- Question cards in the catalog and bookmarks no longer show a "Round N" tag; the tournament and round label ("AVES 2025 · DE 1") already say which round it is.
- **Visual questions**: questions about a figure show it between the question and the choices: in catalog and bookmark cards (lazy-loaded), in solo and multiplayer as soon as the question starts (with the next question's images preloaded and the question text's height reserved so the figure doesn't jump while the text types out), and full-size in a lightbox on click (`Esc` or a click closes it; game shortcuts don't fire while it's open). Visual questions carry a **Visual** tag. A new "Visual questions" filter (Visual / Text only) is in the catalog, solo setup and settings, and multiplayer room settings, and the host validates it like the other filters.
- Visual bonuses are tagged "Visual Bonus" (in the Visual tag's colour) instead of "Bonus" in question cards and in the solo and multiplayer question panels; the separate Visual tag now appears only on visual tossups.
- **Logo and favicon** (since replaced): a Science Bowl buzzer (red dome) with an orbiting electron, on a tile in the site's blue-to-violet accent gradient. It replaces the gradient dot in the nav brand, and every page now links a favicon (`favicon.svg`, with a bolder small-size drawing, plus `favicon.ico` at 16/32/48 px), an Apple touch icon, and a web app manifest with 192/512 px and maskable icons.
- **Faster loading**: the catalog, solo, multiplayer and bookmarks pages preload the question bank from their `<head>`, so the download starts at once instead of after the scripts run; the home page prefetches it into the browser cache while idle (not on Save-Data or 2G); expanding the bank skips the text-cleanup regexes for strings that don't need them (about twice as fast, same output); and packet order is computed with integer ranks and applied without re-sorting on each filter change. On a simulated phone (4× slower CPU, 20 Mbps), the catalog shows results in about 5.7 s instead of 6.8 s when opened directly, and 3.3 s when opened from the home page.
- **Question bank split by tournament and grouped by packet**: `data/questions.json` (31 MB, 7.1 MB gzipped) is replaced by one file per tournament under `data/bank/` (21 MB, 6.7 MB gzipped in all), where each packet's round label, round and URL are stored once instead of on every question, and the tournament name comes from `meta.json`. Pages load the files in parallel and expand each as it arrives. The **Bookmarks** page loads only the tournaments that hold a bookmark (via `data/bank/index.json`), so it shows its cards in about 0.7 s instead of 5.3 s on a simulated phone. `tools/bank.js unpack`/`pack` converts the bank to and from the old flat record list for editing, and the tests check the files are exactly what `pack` writes. Catalog and solo open about 0.6–1 s sooner on a simulated phone.
- **Faster search**: each question's lowercased search text is built once, in idle time after the catalog loads, instead of on every keystroke (about 40 ms per keystroke instead of 110–160 ms on the full bank).
- Catalog search matches each word separately: every word must appear in the question, answer or tournament name, but not next to each other or in the typed order. Each word is highlighted.
- Question cards, the solo answer box and multiplayer reveals show the question's number in its packet: "AVES 2 · DE 4 · Q7".
- Grading and search ignore subscript markup, so "Ksp" matches "K_sp" and "Fe2+" matches "Fe^(2+)". A lone charge after a caret ("H^+", "NO3^-", "e^−") and single Greek letters render as superscripts/subscripts, and a bare exponent that starts with digits takes only the digits ("x^3y" is x³y, "sp^3d" is sp³d).
- Catalog: with no tournament picked, results list the newest tournaments first (each in packet order), using an approximate date per tournament in `meta.json`; picking tournaments lists them A-Z as before.
- Catalog: Prev/Next (and the page box) under the results keep the pager where it was on screen instead of jumping to the top.
- Tournament pickers list the selected tournaments first when opened.
- Solo and multiplayer show a **Source** link to the question's packet next to the tournament, round and question number once the answer is revealed, and in the session log. In multiplayer the link travels with the answer, so it can't be opened before the reveal.
- Chemical formulas in questions, choices and answers display their counts as subscripts (H₂SO₄, Ca(OH)₂), with a guard list for look-alikes such as SN2, sp3 and HSP70.
- Ions written with a superscript charge get their subscripts even when they're one element (H₃⁺), and P680/P700 are no longer read as phosphorus.
- Grading: typing the key exactly now ignores its exponent markup too, so "W+ boson" matches a key stored as "W^+ BOSON" even when "W boson" is on the reject list.
- SEO: descriptive page titles, meta descriptions, canonical URLs, Open Graph/Twitter cards with a 1280×640 preview image (`img/og-image.png`), `sitemap.xml`, a `404.html`, and `noindex` on the per-device bookmarks page. README opens with a keyword-rich summary, live-site link and badges.
- Added an MIT license for the site code (the question data stays with its packets' authors).
- Catalog: on wide screens the tournament picker is a sidebar checklist beside the results, so many more tournaments are visible at once; phones keep the dropdown.
- Multiplayer: clicking the room code copies an invite link that joins the room directly, and every player can rename themselves mid-game.
- Grading counts `1: … 2: …` as item markers (not times, ratios or `row 1:` labels), so about 500 more list and ranking questions grade by item number or name; "put/place/list … in order" is a ranking; rankings can be typed with the item names in order; and a key that answers each item in turn (`1: RIGHT; 2: LEFT`) no longer passes `all` or `123`.
- Grading handles "name any N" keys (any N distinct listed items pass), roman part labels (`I)`, `II)`), and multi-part parts keyed as a letter plus its choice (the letter alone passes).
- The round slider (catalog, solo setup and settings, multiplayer lobby and room settings) spans only the rounds the picked tournaments have, instead of a fixed 1–20; a range that reached the top keeps reaching it, and a narrower one is clamped.
- Grading compares numbers whole (a typed `5.4` no longer passes for `4.5 METERS`, nor `2.3 × 10^23` for `3.2 × 10^23`), accepts scientific notation typed with `x`, `*` or `e`, and lets one part of a multi-part answer be a bare number for a number-and-unit key; a bare number no longer passes when the key goes on with more math (`20 pi`) or a sign word (`870 JOULES LESS`).
- Short-answer grading accepts a unit written out or abbreviated after a number (`10 joules` for `10 J`, `9.8 meters per second squared` for `9.8 m/s^2`, `100 degrees Celsius` for `100 °C`); multiple choice still needs the letter or the exact choice. Also fixed: in a multi-part answer, a number cut out of unseparated words (`4 meters 1/16`) no longer passes for a number-and-unit part (`4 SECONDS`).
